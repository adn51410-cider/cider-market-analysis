# E2E仕様書 - P-001: 市場分析ダッシュボード

**ページID**: P-001
**ルート**: `/`
**権限レベル**: ゲスト（認証不要）
**最終更新**: 2026-01-11

---

## 1. ページ概要

シードルと他の酒類市場を6つの視点で比較分析し、戦略立案に必要な洞察を得るダッシュボードページ。

### 主要機能
- 6つの分析視点の切り替え（市場規模・成長率・価格帯・消費者属性・販売チャネル・季節性）
- 酒類カテゴリーの比較グラフ表示
- インタラクティブなフィルター（期間選択、酒類選択）
- データの自動更新（e-Stat API経由）
- CSV補完インポート機能

---

## 2. E2Eテスト項目

### 正常系（必須）

#### E2E-DASH-001: ページ初期表示
- **概要**: ダッシュボードページが正常に表示される
- **前提条件**: サーバーが起動している
- **操作手順**:
  1. `/` にアクセス
- **期待結果**:
  - ページタイトルが表示される
  - グラフエリアが表示される
  - フィルターパネルが表示される
  - ローディング状態が正常に完了する

#### E2E-DASH-002: データ自動取得
- **概要**: ページ読み込み時にe-Stat APIからデータが自動取得される
- **前提条件**: サーバーが起動している、e-Stat APIが利用可能
- **操作手順**:
  1. `/` にアクセス
  2. APIレスポンスを待機
- **期待結果**:
  - `/api/market-data` APIが呼び出される
  - グラフにデータが表示される
  - エラー表示がない

#### E2E-DASH-003: 分析視点の切り替え
- **概要**: 6つの分析視点を切り替えられる
- **前提条件**: ダッシュボードが表示されている
- **操作手順**:
  1. 分析視点ドロップダウンをクリック
  2. 「成長率」を選択
- **期待結果**:
  - グラフが成長率視点に更新される
  - 軸ラベル・タイトルが変更される

#### E2E-DASH-004: 期間フィルター操作
- **概要**: 開始年月・終了年月を選択してフィルタリングできる
- **前提条件**: ダッシュボードが表示されている
- **操作手順**:
  1. 開始年月フィールドで期間を選択
  2. 終了年月フィールドで期間を選択
  3. 「更新」ボタンをクリック
- **期待結果**:
  - 選択した期間のデータでグラフが更新される
  - APIが新しいパラメータで呼び出される

#### E2E-DASH-005: 酒類カテゴリー選択
- **概要**: 比較する酒類カテゴリーを選択できる
- **前提条件**: ダッシュボードが表示されている
- **操作手順**:
  1. 酒類カテゴリーチェックボックスで「ワイン」「日本酒」を選択
  2. 「ビール」を選択解除
- **期待結果**:
  - グラフに選択したカテゴリーのみ表示される
  - 凡例が更新される

#### E2E-DASH-006: データ更新ボタン
- **概要**: 手動でデータを再取得できる
- **前提条件**: ダッシュボードが表示されている
- **操作手順**:
  1. 「更新」ボタンをクリック
- **期待結果**:
  - ローディング状態が表示される
  - APIが再呼び出しされる
  - グラフが更新される

#### E2E-DASH-007: レポート出力ページへの遷移
- **概要**: レポート出力ページに遷移できる
- **前提条件**: ダッシュボードが表示されている
- **操作手順**:
  1. 「レポート出力」ボタンまたはリンクをクリック
- **期待結果**:
  - `/report` ページに遷移する
  - 選択した分析設定が引き継がれる

### 異常系

#### E2E-DASH-008: API エラー時の表示
- **概要**: APIエラー時に適切なエラーメッセージが表示される
- **前提条件**: APIがエラーを返す状態（ネットワーク遮断等）
- **操作手順**:
  1. APIがエラーを返すよう設定
  2. `/` にアクセス
- **期待結果**:
  - エラーメッセージが表示される
  - アプリケーションがクラッシュしない
  - リトライオプションが表示される（任意）

#### E2E-DASH-009: 不正な期間選択
- **概要**: 開始年月が終了年月より後の場合のバリデーション
- **前提条件**: ダッシュボードが表示されている
- **操作手順**:
  1. 開始年月を「2025-12」に設定
  2. 終了年月を「2025-01」に設定
  3. 「更新」ボタンをクリック
- **期待結果**:
  - バリデーションエラーが表示される
  - 不正なAPIリクエストが送信されない
